# Intro to Coding

## Session 5 — Endings, Polish, and Publishing

Welcome to **Session 5** of *Intro to Coding*!

In Session 4, students improved visuals and atmosphere.  
In **Session 5**, students finish their game by adding:

- Better endings
- Gameplay polish
- Safe ways to publish and share

By the end of this session, students will have a complete adventure game they can replay and show to family/friends.

---

## 🎯 What Students Will Do in Session 5

In this session, students will:

- Build multi-route adventures with meaningful preparation choices
- Add adversaries with simple chance-based battles (dice-style rolls)
- Track HP, battles won, and equipment modifiers
- Add final ending logic and replay/reset flow
- Prepare the project for publishing

---

## 📁 Files in This Folder

Session 5 uses **four files**:

- `index.html` → Layout + HUD + inventory sections
- `style.css` → Final visual polish
- `story.js` → Story routes, endings, and battle nodes
- `script.js` → Engine logic (state, battle, equipment, endings)

---

## 🧠 Session 5 Concepts

Students practice:

- Combining story branching + game state + simple combat
- Distinct inventory categories (general, weapons, defense)
- Risk/reward choices (attack vs retreat)
- Persistent world changes (defeated enemies stay defeated)
- Finishing and polishing a full project

---

## 🌍 Publishing (Safe + Free First)

**Always publish with parent/guardian or teacher help.**

### Free options (recommended for students)

1. **GitHub Pages** (free)
   - Great for static HTML/CSS/JS projects
   - Works directly from a GitHub repository

2. **Cloudflare Pages** (free)
   - Free static hosting
   - Fast and reliable

3. **Netlify Free plan** (free)
   - Drag-and-drop deploy available
   - Static projects work well

4. **Vercel Hobby plan** (free)
   - Free for personal static sites

### Low-cost simple hosting (if needed)

- **Neocities Supporter** (low monthly cost)
- **Namecheap shared hosting** (budget starter plans)
- **Hostinger basic shared plans** (budget)

If publishing is not allowed yet, students can still share by running locally on a family computer.

---

## 🆘 Safety Notes for Kids

- Do not post personal info (full name, address, school, phone, email)
- Use a parent/guardian account when required
- Ask an adult before making anything public
- Keep comments and game text kind and respectful
